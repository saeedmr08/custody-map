# Security

CustodyMap is a **portfolio MVP** for explaining personal-data flows. It is not a production privacy platform.

## Data handling

- Graph nodes, edges, and subject refs are synthetic demo strings.
- Nothing is sent to a backend; request state stays in browser memory.
- Retention math is illustrative and not legal advice.

## Do not

- Enter real names, emails, national IDs, or production system identifiers.
- Treat fulfilled/rejected demo requests as evidence of GDPR/CCPA fulfillment.
